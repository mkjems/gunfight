# Highscores

The running server should keep a record of all the games played (to a limit) and provide a high score table on the high scores screen.

| player name  | wins  | kills  | deaths  |   |
|---|---|---|---|---|
| LUK  | 10  | 40  | 20  |   |
| MAX  | 8  | 31  | 16  |   |
| MAR  | 7  |  21 | 12  |   |

The server will forget all about these scores when it is restarted.
