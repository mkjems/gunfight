All documentation is in the documentation folder

Main  specification file is documentation/Specification-main.md but there are other files for specific areas.

Completed-plans folder is a graveyard for plans/doc we have completed and are not changed or kept up to date any more. The rest the documents we try yo keep as accurate as possible. Therefore it is important to be precise and terse in the language, but at the same time give a complete picture.

The human write the specifications but the agents help with keeping it up to date as work is done and the project evolves.

For daily work, agents and human collaborate to describe/outline what the next changes will be, in the form of checkmark and tasks in TODO files.

When we agree that the work described in the TODO is sensible and good we implement it.  

The agents writes the code so it performs as per the specification/documentation and the TODO files.

The agent marks the todo as done and updates the specification files if needed
